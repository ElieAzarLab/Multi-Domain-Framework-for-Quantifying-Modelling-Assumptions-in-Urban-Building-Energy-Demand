Databases used for the simulations. Canadian code-compliant database is available [here](https://github.com/ElieAzarLab/CEA-Database-Canada). 

1. Database_Base represents the calibrated database.
2. Database_EV25 represents the addition of 25% EV adoption in each building.
3. Database_EV50 represents the addition of 50% EV adoption in each building.
4. Database_EV75 represents the addition of 75% EV adoption in each building.
5. Database_EV100 represents the addition of 25% EV adoption in each building.
